# PDF FREE – by TESC-GV

Công cụ chuyển **PDF sang Word (.docx)** chạy ngay trên trình duyệt, xử lý offline, không tải file lên máy chủ nào.

## Dùng online
https://tesc-gv.github.io/PDF-BY-TESC-GV/

## Cài lên máy như một ứng dụng
1. Mở link trên bằng **Chrome** hoặc **Edge**.
2. Bấm biểu tượng **Cài đặt** (hình màn hình có mũi tên) ở cuối thanh địa chỉ, hoặc menu `⋮` → *Cài đặt PDF sang Word - TESC*.
3. Ứng dụng có icon trên Desktop/Start Menu, mở cửa sổ riêng và dùng được khi không có mạng (sau lần mở đầu tiên).

## Dùng offline hoàn toàn (máy không có mạng)
Tải file `index.html` (nút **Download raw file** trên GitHub), copy vào máy, bấm đúp để mở bằng trình duyệt.

## Cập nhật phiên bản
1. Thay file `index.html` mới (nhớ giữ lại 2 dòng thêm vào đầu và cuối file để PWA hoạt động, hoặc nhờ Claude đóng gói lại).
2. Mở `sw.js`, tăng số ở `VERSION` (ví dụ `tesc-pdf-v2`).
3. Commit. Sau 1–2 phút các máy sẽ tự nhận bản mới ở lần mở kế tiếp.
